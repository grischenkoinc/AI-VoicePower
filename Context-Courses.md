# Context-Courses.md — контент курсів

## Реєстр курсів

Усі 7 курсів реєструються через `app/src/main/java/com/aivoicepower/data/content/CourseContentProvider.kt` → `getAllCourses()`. Кожен курс — окремий об'єкт у `app/src/main/java/com/aivoicepower/data/content/courses/*.kt`. Разом **140 уроків** (перевірено в застосунку: екран "Курси" показує "7 курсів • 140 уроків" — відповідає сумі нижче).

| Курс (файл) | Уроків написано / всього | Стан |
|---|---|---|
| `ClearSpeechCourse.kt` (Course 1, "Чітке мовлення за 21 день") | 21/21 | ✅ Повністю готовий |
| `CleanSpeechCourse.kt` (Course 5) | 14/14 | ✅ Повністю готовий |
| `IntonationMagicCourse.kt` (Course 2) | 7/21 | ⏳ Дні 8-21 — заглушки |
| `VoicePowerCourse.kt` (Course 3) | 7/21 | ⏳ Дні 8-21 — заглушки |

| `CharismaticSpeakerCourse.kt` (Course 7) | 7/21 | ⏳ Дні 8-21 — заглушки |

**Разом: 2 з 7 курсів повністю готові, 5 з 7 мають лише тиждень 1.**

## Формат заглушки

Уроки-заглушки (дні 8-21) виглядають так:
```kotlin
Lesson(
    ...
    description = "Скоро буде доступно",
    theory = TheoryContent(
        text = "Цей урок ще в розробці. Ми працюємо над тим, щоб зробити його якомога кориснішим для тебе. Дякуємо за терпіння!",
        tips = emptyList()
    ),
    exercises = emptyList(),
    ...
)
```
- `BusinessCommunicationCourse.kt`, `CharismaticSpeakerCourse.kt`, `ConfidentSpeakerCourse.kt` — усі 14 заглушок днів 8-21 генеруються **однією спільною функцією** `createPlaceholder(day)` (назва/опис не відрізняються по днях).
- `IntonationMagicCourse.kt`, `VoicePowerCourse.kt` — заглушки мають **окремі функції на кожен день** (`getLesson8Placeholder()` ... `getLesson21Placeholder()`), і назви вже унікальні й тематичні (напр. "Грудний резонатор", "Головний резонатор" для IntonationMagic) — сама теорія/вправи все ще порожні, але заголовки вже продумані, легше писати по них контент.

## Чому це критично

- Уроки розблоковуються **послідовно** (пройшов день N → відкрився N+1), тому активний користувач впирається в заглушку приблизно на 2-му тижні курсу.
- Реальний ризик: платний підписник (перша оплата — вересень 2026) саме зараз може впертися в порожній урок → ризик відмови від підписки/рефанду.

## Стиль і консистентність (витягнуто з аналізу 94 реальних уроків, 2026-09-21)

Це не загальні поради, а виміряні патерни з коду (`Lesson.kt`, `TheoryContent.kt`, `LessonExercise.kt` + 94 написаних уроки). Дотримуватись максимально точно — 3 курси (ConfidentSpeaker/Business/Charismatic) показують 100%-ву дисципліну по цих правилах.

### Розмір/форма уроку
- **`theory.tips` — рівно 3 пункти, завжди, без винятків** (перевірено на всіх 94 уроках). Найжорсткіша конвенція в датасеті.
- **`exercises` — типово 7** (діапазон 6-9). 6 — легший/підсумковий день, 8-9 — щільніший чи "тиждень-фінал" день.
- **`estimatedMinutes` — 10-18, зростає** протягом курсу й особливо в кінці тижня/курсу (див. прогресію нижче).
- `durationSeconds` вправ — з фіксованого набору **{45, 60, 90, 120}** для звичайних вправ; 150-180 лише для фінальної FREE_SPEECH; 420 — рідкісний виняток ("повний комбо-розминка" на підсумковий день.
- `repetitions` поле практично не використовується — кількість повторів пишеться прямо в `instruction` ("Повтори 5 разів").
- `LessonExercise.difficulty` (enum BEGINNER/INTERMEDIATE/ADVANCED) — фактично не використовується, лишай дефолт. Реальна складність — поле `difficulty: Int` (1-5) всередині `ExerciseContent.TongueTwister`, і воно є лише в ClearSpeechCourse (діти-специфічна діагностика).
- `order` поле — ніколи не задається, покладаються на порядок у списку.

### Стиль теорії ("ти", не "ви")
Майже завжди такий скелет (не обов'язково всі пункти в кожному уроці, але це домінантний шаблон):
1. **Хук-теза першим рядком** (не буквально назва уроку) — напр. "Слова-паразити — це не лінь говорити, це звичка, яку можна змінити".
2. Аналогія/риторичне питання/приклад.
3. Визначення поняття.
4. Список ("Три кити...", "Топ-10...", "Базові елементи...").
5. **"Цікавий факт:"** — майже завжди дослідження/статистика з конкретним числом (Harvard Business Review, Duke University тощо).
6. **"Типова помилка:"** — поширена хибна думка, спростована.
7. **"Ключовий інсайт:"** — фінальний синтез.
8. Місток до наступного ("Наступний тиждень буде про...").

⚠️ **Дисципліна різниться по курсах** — для ConfidentSpeaker/Business/Charismatic усі 3 фрази ("Цікавий факт"/"Типова помилка"/"Ключовий інсайт") зустрічаються **в кожному з 7 написаних уроків без винятку** — тримати цю саму дисципліну в днях 8-21. IntonationMagic — навпаки, значно терсіший/списковіший (майже без "Цікавого факту"), VoicePower — проміжний варіант. Пиши в стилі, який уже встановлений у днях 1-7 ТОГО САМОГО курсу.

**Довжина**: 260-380 слів (~9-13 коротких абзаців), прості декларативні речення, зрідка риторичні питання. **Без markdown `**bold**` заголовків усередині тексту** — це один задокументований виняток (CharismaticSpeaker день 4, там 631 слово й markdown), не норма, не наслідувати.

### Композиція вправ (порядок easy→hard, не пари)
- Уроки мають 6-9 вправ, тому "легка+важка" — це не пара, а весь прогон: **типово 5 ARTICULATION-дрилів → 1 READING (опційно) → 1-2 FREE_SPEECH в самому кінці**. FREE_SPEECH практично завжди останній(і) — це "велика записувана практика", що закриває урок.
- У non-diction курсах (Clean/Confident/Business/Charismatic) `ExerciseType.ARTICULATION` — це загальний "дрил"-кошик (дихання, паузи, повторення фраз, постава), не буквально артикуляційна гімнастика.
- VoicePowerCourse (дні про дихання) вплітає `BREATHING` вправи серед ARTICULATION.
- Найважча вправа уроку — зазвичай остання скоромовка/TONGUE_TWISTER_BATTLE в кінці тижня, а не строго зростаюча складність по порядку всередині одного уроку.

### Прогресія складності по тижнях (тема = тиждень)
- Тиждень 1 = основи (окремі теми/звуки), **день 7 = "Підсумок тижня"** (список усіх уроків тижня + місток далі).
- Тиждень 2 = нюанси/комбінації, **день 14 = "Підсумок тижня 2"**.
- Тиждень 3 = майстерність/застосування, **день 21 = випускний/фінальний тест**.
- `estimatedMinutes` зростає монотонно і стрибає на днях 7/14/21 (напр. ClearSpeech: 10→12 у тижні 1, →15 на дні 7, →15 на дні 14, →18 на дні 21 — найвище значення курсу).
- **День 21 (чи 14 для 14-денних курсів) структурно особливий**, не просто "важчий": явне обрамлення випуску ("Вітаю, випускнику!"), порівняння "день 1 vs фінал", підсумок усього курсу (не лише тижня), стратегія підтримки "після курсу", найвище `estimatedMinutes` курсу, більше FREE_SPEECH-вправ на рефлексію.

### "Розминка" — як це насправді працює
Окремого поля/прапорця "warmup" у моделі даних **немає**. Те, що виглядає як розминка — це просто порядок вправ (легші дрили спочатку, важче/записуване — в кінці). Є ще окрема секція застосунку "Warmup" (інша частина навігації, не курси) — теорія деяких уроків згадує її побіжно ("перед КОЖНИМ уроком виконуй розминку з розділу Warmup"), але це посилання на іншу фічу, не частина самого уроку.

### Tips — стиль
Завжди рівно 3, кожен — повне наказове речення. Патерн (помірна впевненість, не залізне правило): tip 1-2 практичні ("Записуй себе щодня — це найкращий спосіб відслідковувати прогрес"), tip 3 — часто настановчий/про самоприйняття ("Не суди свій голос зараз"). На підсумкових/фінальних днях tips стають ретроспективними ("Порівняй себе з початком курсу").

### Інші конвенції
- **Назви вправ**: короткі іменникові фрази, іноді з уточненням у дужках: "Скоромовка 2 (фінальний челендж)", "Діагностичний запис 'до курсу'" (стандартна назва для baseline-запису дня 1).
- **Naming id**: кожен курс має власні префікси (`LESSON_PREFIX`/`EXERCISE_PREFIX`, напр. `clean_lesson_`/`clean_ex_` для CleanSpeech, `speaker_lesson_`/`speaker_ex_` для ConfidentSpeaker) — використовувати те, що вже задано в конкретному файлі курсу, не вигадувати нове.
- **`targetMetrics`**: 1-3 `SkillType` на вправу, підсумкові FREE_SPEECH накопичують більше метрик (3+), ранні дрили — менше (1).
- **Course-level `difficulty`** (на весь курс, не по уроках): ClearSpeech/CleanSpeech/IntonationMagic = BEGINNER; VoicePower/ConfidentSpeaker/Business = INTERMEDIATE; Charismatic = ADVANCED — сигнал, наскільки просунуту лексику/концепції можна закладати в теорію.

### Практична порада для днів 8-21
- **IntonationMagic, VoicePower** — назви днів уже готові (див. чекліст нижче), і сам курс уже показав власний стиль (списковіший/терсіший для Intonation, дихально-орієнтований для VoicePower) — писати "в тон" дням 1-7 того самого файлу.
- **ConfidentSpeaker, Business, Charismatic** — назв немає, потрібно вигадати теми тижнів 2-3, дотримуючись арки "основи → нюанси/комбінації → майстерність/застосування → випускний", і при цьому тримати 100%-ву дисципліну "Цікавий факт/Типова помилка/Ключовий інсайт" у кожному уроці, як у їхніх власних днях 1-7.
